# Ratchet learnings

Every Ratchet agent reads this file before starting work. Entries come from human reviews and repeated gate failures.

- (2026-10-01, env:spike) Local Mule toolchain (Rahil wants full runtime verification on this machine): run Java/Maven/Mule via 'mise exec --' from the repo root (mise.toml: Temurin 17, Maven 3.9.16, MULE_HOME=~/.local/share/mule/mule-standalone-4.9.0, Mule Kernel CE). Proven versions: mule-maven-plugin 4.10.1, mule-http-connector 1.11.3, mule-objectstore-connector 1.2.2, mule-validation-module 2.0.9; repos https://repository.mulesoft.org/releases/ and https://repository.mulesoft.org/nexus/content/repositories/public/. Newer http 1.12.x / validation 2.0.10 fail to deploy on 4.9.0 (EnumConstantNotPresentException JAVA_25). Deploy signal: apps/<name>-anchor.txt or 'Started app' in logs/mule.log; failure: 'Failed to deploy artifact'. Working example: <run>/reference/mule-smoke/.
- (2026-10-01, gate:adversarial) Filesystem safety in a2m: every delete/overwrite goes through one guarded helper that refuses symlinks at any path component and anything not strictly inside the results folder; every per-input-item operation (discovery, zip extraction, reading) is isolated so one bad item is refused and logged, never crashing the batch. Proxy names are validated (no control chars incl. newlines).
- (2026-10-01, env) Static checks are available in the venv: .venv/bin/ruff check a2m tests and .venv/bin/mypy a2m (installed Oct 1 2026). Run them before handing back.
- (2026-10-01, orchestrator) When the user picks an option that changes a locked config value (e.g. review round caps), register it with ask choice --locked so the pick also counts as approve-changes; otherwise the user has to confirm twice.
- (2026-10-02, gate:adversarial) Tests assert behaviour, never exact source text, call strings, AST shape of named functions or docstring wording; class-wide invariant sweeps (e.g. only safefs deletes) are fine.
- (2026-10-02, human) Review findings must have a real functional impact (wrong output, crash/hang, data loss, security, broken contract, dishonest report). Wording, style, docstrings, extra tests for working behaviour, and theoretical edge cases are notes, not findings (Rahil 2026-10-02; standards.md R1-R3).
